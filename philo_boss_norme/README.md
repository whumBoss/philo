# Philosophers

## Description
The **Philosophers** project is an introduction to multithreading, concurrent programming, and shared memory management in C. Based on Edsger Dijkstra's classic *Dining Philosophers Problem*, this project illustrates the core challenges of multithreaded systems: resource sharing, race condition prevention, and avoiding deadlocks.

The goal is to simulate a scenario where one or more philosophers sit around a round table with a large bowl of spaghetti in the middle and a limited number of forks. Philosophers alternate between three states: **eating**, **thinking**, and **sleeping**. To eat, a philosopher must pick up both their left and right adjacent forks. A philosopher dies if they do not start eating within a given timeframe.
